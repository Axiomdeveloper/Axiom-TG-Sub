# Axiom TG — ساب خودکار V2Ray از کانال‌های تلگرام

[![auto-update](https://img.shields.io/badge/update-every_5h-00e0a4)](#)
[![retention](https://img.shields.io/badge/retention-48h-7c5cff)](#)
[![channels](https://img.shields.io/badge/channels-8-0aa3ff)](#)

هر **۵ ساعت**، آنتی‌اکشن (GitHub Action) کانفیگ‌های **۲۴ ساعت اخیر** هشت کانال تلگرامی را می‌خواند، نام همه را به
**`Axiom TG`** تغییر می‌دهد و در قالب یک **Subscription** واحد منتشر می‌کند. کانفیگ‌ها پس از **۴۸ ساعت** خودکار از
آرشیو حذف می‌شوند. آمار (کانال‌به‌کانال، مجموع، تعداد کاربران ساب) بین دو مارکر پایین به‌صورت خودکار بازنویسی می‌شود.

Every 5 hours, a GitHub Action scrapes the last 24 hours of 8 Telegram channels, renames every V2Ray config to
**Axiom TG**, and publishes a single rolling subscription (48h retention). Stats below are auto-regenerated.

## معماری / Pipeline

```
 .github/workflows/axiom-update.yml   cron: "7 */5 * * *"  (هر ۵ ساعت)
                │
                ▼
 scripts/fetch_configs.py
   ├─ t.me/s/<channel>  → پست‌های ۲۴ ساعت اخیر
   ├─ استخراج vless/vmess/trojan/ss/ssr/tuic/hy2/...
   ├─ ری‌نیم → #Axiom TG + ps در VMess
   ├─ آرشیو ۴۸ ساعته (history/archive.json) + حذف قدیمی‌ها
   ├─ sub/axiom_sub.txt (base64) + sub/axiom_plain.txt
   ├─ stats.json  ← مجموع، کانال‌به‌کانال، کاربران
   └─ README stats block (این فایل)
                │
                ▼ (اختیاری)
 POST <APP_URL>/api/ingest  ──►  داشبورد Next.js (Postgres)
                                  ├─ /api/sub    ساب زنده + شمارش کاربران
                                  ├─ /api/stats  JSON + shields badge
                                  └─ صفحه‌ی اصلی فارسی با آمار زنده
```


## نکات / Notes

- **تغییر فاصله‌ی به‌روزرسانی:** خط `cron: "7 */5 * * *"` در ورک‌فلو و مقدار `updateEveryHours` در `fetch_configs.py` — cron به UTC است («دقیقه‌ی ۷، ساعت‌های ۰/۵/۱۰/۱۵/۲۰ UTC»).
- **تغییر نام کانفیگ‌ها:** ثابت `BRAND` در `scripts/fetch_configs.py` (پیش‌فرض `Axiom TG`).
- **تغییر پنجره‌ها:** `SCAN_WINDOW = timedelta(hours=24)` و `RETENTION = timedelta(hours=48)`.
- **افزودن/حذف کانال:** لیست `CHANNELS` در `scripts/fetch_configs.py` و `src/lib/types.ts`.
- منبع داده صفحات عمومی `t.me/s/<channel>` است — **نه اکانت تلگرام لازم است، نه Bot Token، نه API key**؛ کانال بدون پیش‌نمایش عمومی `FAIL` می‌شود و بقیه متوقف نمی‌شوند.
- `history/archive.json` چرخه‌ی ۴۸ ساعته است؛ ویرایش دستی نکنید.
- رهگیری کاربران: فقط **هش نمک‌دار** IP+User-Agent ذخیره می‌شود، نه خود IP.
- این پروژه صرفاً پیوندهای عمومی منتشرشده را تجمیع و تغییر نام می‌دهد؛ مسئولیت استفاده بر عهده‌ی کاربر است.
